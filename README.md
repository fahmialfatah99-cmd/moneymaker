# 💰 MoneyMaker Pro - Tools & Automation Penghasil Uang

Aplikasi web dashboard lengkap dengan 9 tools automation untuk membantu Anda menghasilkan uang secara online. Dirancang khusus untuk freelancer, content creator, dan entrepreneur digital.

## 🚀 Fitur Utama

### 9 Tools Powerful untuk Menghasilkan Uang

1. **📊 Dashboard** - Overview semua tools, earning, dan analitik bisnis Anda
2. **📄 Invoice Generator** - Buat invoice profesional untuk klien dengan kalkulasi otomatis
3. **📈 Passive Income Calculator** - Hitung dan proyeksi penghasilan pasif dari berbagai sumber
4. **🎯 Side Hustle Tracker** - Track pendapatan dari berbagai usaha sampingan
5. **⚡ Content Generator** - Generate konten marketing, blog, social media, dan ad copy
6. **📧 Email Template** - Buat template email marketing yang converting
7. **🔍 SEO Meta Generator** - Generate meta tags dan optimasi SEO untuk website
8. **💵 Pricing Calculator** - Hitung harga produk/jasa yang optimal
9. **💼 Freelance Manager** - Kelola project, klien, dan pipeline freelance

## 📦 Instalasi

```bash

git clone https://github.com/yourusername/moneymaker-pro.git

# Masuk ke directory
cd moneymaker-pro

# Install dependencies
npm install

# Jalankan development server
npm run dev

# Build untuk production
npm run build
```

## 📖 Panduan Penggunaan

### 1. Dashboard
- Lihat overview total income, active projects, dan growth rate
- Monitor revenue dan expense dengan chart interaktif
- Akses cepat ke semua tools
- Lihat recent activity dan tips monetisasi

### 2. Invoice Generator
- Isi detail invoice (nomor, tanggal, jatuh tempo)
- Tambahkan info pengirim dan penerima
- Tambah item dengan deskripsi, quantity, dan harga
- Preview invoice sebelum download
- Download invoice sebagai file text

### 3. Passive Income Calculator
- Tambahkan sumber passive income (dividen, sewa, dll)
- Input investasi awal dan return bulanan
- Atur proyeksi tahun dan compound growth
- Lihat chart distribusi income dan proyeksi
- Hitung total income per bulan/tahun

### 4. Side Hustle Tracker
- Track berbagai side hustle (freelance, content, affiliate, dll)
- Input income, expense, dan jam kerja
- Hitung profit dan hourly rate
- Lihat chart profit per side hustle
- Identifikasi side hustle paling profitable

### 5. Content Generator
- Pilih jenis konten (blog, social media, ad copy, email, product, headline)
- Input topik dan target audience
- Generate 3 variasi konten siap pakai
- Copy konten dengan satu klik
- Gunakan untuk marketing dan monetisasi

### 6. Email Template
- Pilih template (welcome, promo, abandoned cart, follow up, newsletter, launch)
- Customisasi dengan brand name, offer, dan CTA
- Preview email dalam format HTML
- Copy template untuk digunakan di email marketing tool
- Tingkatkan konversi dengan template proven

### 7. SEO Meta Generator
- Input target keyword dan brand name
- Generate title tag, meta description, dan OG tags
- Lihat preview Google search result
- Dapatkan suggested keywords dan headings
- Copy semua meta tags untuk website Anda
- Tingkatkan traffic organik

### 8. Pricing Calculator
- Pilih tipe pricing (produk, jasa, subscription)
- Input costs, margin, dan target revenue
- Dapatkan recommended price
- Lihat pricing strategies (penetration, competitive, premium, value-based)
- Buat pricing tiers (Basic, Standard, Premium)
- Maximize profit dengan pricing yang tepat

### 9. Freelance Manager
- Kelola semua project dalam satu tempat
- Track status (proposal, in progress, review, completed, paid)
- Monitor pipeline dan total earned
- Database klien dengan total spending
- Update status project dengan mudah
- Tingkatkan produktivitas dan income
